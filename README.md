# Cosmos Preview

Frontend preview de Cosmos Pay.

## Sitio web

- Producción: https://cosmos.cloudycoding.com/

## Proyecto

El código de la aplicación vive en:

- `/home/runner/work/Cosmos-preview/Cosmos-preview/cosmos-pay-frontend-master`

Está construido con:

- React 19
- TypeScript
- Vite
- React Router
- i18next

## Desarrollo local

Desde `/home/runner/work/Cosmos-preview/Cosmos-preview/cosmos-pay-frontend-master`:

```bash
npm install
npm run dev
```

## Scripts disponibles

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
